# folia v0.1.0

Markdown を持ち出せる個人用ワークスペースの最初のリリースです。

## できること

- 階層ページ、テンプレート、検索、お気に入り、ページ URL と戻る / 進む
- 見出し、リスト、チェックリスト、引用、コード、ブロックのドラッグ、Undo / Redo
- ページリンクとバックリンク
- タスクのテーブル・カンバン・カレンダー、ステータス・優先度・期限
- ブラウザ内への自動保存、ゴミ箱、JSON バックアップ、Markdown の入出力

## 起動

Node.js 22 以上で、ソースのディレクトリから `npm start` を実行し、http://127.0.0.1:3000 を開いてください。アプリの起動に依存パッケージのインストールは不要です。ポートは `PORT`、待ち受け先は `HOST` で変更できます。

## 品質確認

自動テスト 67 件と Chromium の実画面テスト 17 シナリオが成功しました。起動時の 404、行分割後のカーソル位置、コード内のバッククォートを含む Markdown の往復を修正しています。README の GIF は実画面の自動操作から作成しました。

詳細は [受け入れ結果](v0.1-acceptance.md) を参照してください。

## 現時点の制限

保存先はブラウザ内です。同期・ログイン・共同編集は含みません。ページ URL は対象ページが同じブラウザにある場合に使えます。タスクのプロパティは固定です。OS の IME の手動確認、Firefox / Safari、タッチ実機の確認は未実施です。Markdown の対応範囲は README を確認してください。
