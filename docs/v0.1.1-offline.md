# v0.1.1 オフライン対応

初回のオンラインアクセス後にアプリ本体を保存し、ネットワーク接続がなくても起動・編集・バックアップできるようにします。ページ・タスク・ゴミ箱の保存場所は従来の localStorage のままです。

## 操作

- サイドバーに「オフライン起動 OK」が表示されたら準備完了です。
- 接続がない場合は「オフラインで編集中」と表示します。
- 対応ブラウザでインストールが可能になると、「アプリをインストール」を表示します。ブラウザのアプリメニューからも利用できます。
- 新しい版の準備ができたら「更新して再読み込み」を表示します。自動では再読み込みしません。
- 未保存の内容がある場合はバックアップを案内し、複数の folia のタブがある場合は他のタブを閉じてから更新します。

初回アクセスには HTTP サーバーが必要です。Service Worker は HTTPS または localhost / 127.0.0.1 で利用できます。通常の LAN 上の HTTP アドレスではオフライン機能を利用できません。ブラウザのデータ削除ではページもキャッシュも消えるため、JSON バックアップは継続してください。アプリをインストールしてもサーバー同期は行いません。

## 更新の仕組み

一式のキャッシュが完成してから切り替えます。必要なファイルがひとつでも取得できなければ、その更新を破棄して旧版を維持します。新旧モジュールの混在を避けるため、同じ版の HTML・JavaScript・CSS をまとめて配信します。他のアプリのキャッシュは削除しません。

配布内容を変更するときは `sw.js` のキャッシュ版を更新してください。ランタイムのファイルを追加したときは precache リストも更新します。自動テストがリストに不足しているモジュールを検出します。

## 検証

- Node の自動テスト：73 件成功。
- 既存の Chromium 実画面テスト：17 シナリオ成功。
- オフライン専用の Chromium 実画面テスト：7 シナリオ成功。

専用テストでは、初回準備、接続なしの再読み込み・編集・バックアップ、複数タブでの更新保留、更新後のデータ保持、不完全更新後の旧版起動、未保存内容がある場合の更新保留、通常プロファイルでの PWA インストール条件を確認します。テスト用サーバーは別のポートを使い、実ファイルを変更せずに新旧の Service Worker を配信します。

```sh
npm ci
npx playwright install chromium
npm run test:offline
```

専用テストは HTTP サーバーも自動で起動・停止します。結果は `artifacts/offline-results.json` に保存します。インストール後の OS のウィンドウ操作、実機 iOS / Safari のホーム画面追加は未確認です。
