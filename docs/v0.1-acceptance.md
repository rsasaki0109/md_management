目標は「自分が毎日使える、Markdown を持ち出せる個人用 Notion」。機能追加を止め、日常利用に必要な操作を Chromium で確認しました。

| 完成条件 | 確認内容 | 結果 |
| --- | --- | --- |
| 書ける | 日本語の変換・確定、途中での行分割、ブロック変換、Undo / Redo、実際のマウスドラッグ | 自動操作で成功 |
| 整理できる | テンプレート、検索、戻る / 進む、URL 復元、ページリンク、バックリンク、クリップボード | 成功 |
| 管理できる | 同じタスクのボード / テーブル / カレンダー表示、ドラッグによる列移動、期限付きタスクの追加 | 成功 |
| 戻せる | 再読み込み後の保存、JSON 書き出し・復元、ゴミ箱からの復元、破損データの保護、容量不足時の救出 | 成功 |
| 実際に使える | デスクトップ 1440 × 1000、モバイル幅 390 × 844、横はみ出し、操作中の JavaScript エラー | 成功 |

## 検証結果

- Node の自動テスト：67 件成功。
- Chromium 実画面シナリオ：17 件成功。
- 構文チェック、差分の空白チェック：成功。
- 実画面 GIF：46 フレーム、1080 × 692、約 11.5 秒、ループ再生。画像フレームを確認済み。
- テストは新しいブラウザコンテキストと架空のデータを使用。普段のブラウザのデータは操作しません。

`qa/browser.mjs` が各シナリオを実行し、`artifacts/browser-results.json` と画面キャプチャを保存します。CI にも同じ実画面テストを組み込みました。CI 上の結果は実行後の Actions で確認できます。

## 見つけて修正した不具合

1. **起動時の `/` が 404**：ルートディレクトリとその配下を正しく区別するよう修正。HTTP のルート・静的ファイル・HEAD・不正リクエストを回帰テストに追加。
2. **行の途中で Enter 後、入力が行末に入る**：分割後のカーソルを次のブロックの先頭へ移すよう修正。Chromium で `abc|def` → Enter → `Xdef` を確認。
3. **コード内のバッククォートで Markdown が崩れる**：内容より長いコードフェンスを使い、読み込み時には開いたフェンスに対応する長さで閉じるよう修正。モデルとブラウザの往復で確認。

## 検証の範囲

日本語入力は Chromium の DevTools Protocol による IME composition / commit で確認しました。OS の日本語 IME を人が操作した確認、Firefox / Safari、実機のタッチ操作は未実施です。モバイル確認は Chromium の表示幅変更です。完全な Unicode・Markdown 全仕様の互換性を保証するものではありません。

保存は同じブラウザ・同じオリジンの localStorage です。バックアップを定期的に書き出してください。共同編集・ログイン・サーバー保存は v0.1 の対象外です。
