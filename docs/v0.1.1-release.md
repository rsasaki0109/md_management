# folia v0.1.1

初回アクセス後、接続がなくても起動・編集できる個人用ワークスペースになりました。

## 新しい機能

- アプリ本体を保存し、オフラインで再読み込み・編集・JSON バックアップ
- 対応ブラウザで PWA としてインストール
- 接続状態、オフライン起動の準備状況、更新通知をサイドバーに表示
- 更新は利用者の操作で適用し、未保存の内容や別タブがある場合は保留
- 不完全な更新は破棄し、使えていた旧版を維持

ページ・タスク・ゴミ箱の保存先と形式は v0.1.0 と同じです。既存のデータはそのまま使用できます。

## 起動とオフライン利用

Node.js 22 以上で `npm start` を実行し、http://127.0.0.1:3000 を開きます。初回アクセスにはサーバーが必要です。サイドバーの「オフライン起動 OK」が準備完了の目印です。

Service Worker は HTTPS または localhost / 127.0.0.1 で利用できます。通常の LAN の HTTP アドレスでは利用できません。保存先は引き続きブラウザ内で、同期機能はありません。JSON バックアップは継続してください。
